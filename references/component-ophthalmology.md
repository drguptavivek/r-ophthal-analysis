# Component: Ophthalmology Definitions

Use this component when defining ophthalmology variables, outcomes, denominators, or visual acuity classifications.

Before analysis, make the row unit explicit: person, eye, visit, image, scan, lesion, or procedure.

Read `clinical-ophthalmology-guidelines.md` for full definitions.

Always state:

- eye-wise versus person-wise analysis
- right eye, left eye, better eye, worse eye, any eye, both eyes, or both eyes with clustering adjustment
- PV/PVA, uncorrected VA, BCVA, correction status, and VA scale
- handling of CF, HM, LP, NLP values
- WHO visual impairment categories and exact thresholds
- missing, ungradable, absent, pseudophakic, or excluded eyes

For person-level outcomes derived from eye data, define whether presence is based on any eye, both eyes, better eye, worse eye, selected eye, or eye-wise analysis with clustering.
